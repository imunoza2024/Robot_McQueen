# Robot_McQueen

"Un robot, mil obstáculos... ¡soy velocidad!" 

En este blog voy documentando el paso a paso de las prácticas de la asignatura: sensores, algoritmos de navegación y unos cuantos choques contra la pared antes de lograr el trazado perfecto.

En cada entrada encontrarás:

El Desafío: Objetivos y planteamiento de la práctica.

Bajo el Capó: Algoritmos, sensores y código utilizado.

La Meta: Resultados obtenidos, derrapes inesperados y lecciones aprendidas.
